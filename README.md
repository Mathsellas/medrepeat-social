# medrepeat-social

Mídias públicas das redes sociais do MedRepeat (Instagram e TikTok), usadas pelo
Metricool para agendar os posts. Uma pasta por post, com a data de publicação.

Tudo aqui é público. Só entram peças de divulgação: nunca dado de usuário,
de paciente ou print com nome, e-mail ou CPF.
